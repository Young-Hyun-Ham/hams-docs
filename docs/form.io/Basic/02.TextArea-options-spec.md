# Text Area 옵션 스펙

## 문서 기준

| 항목 | 내용 |
| --- | --- |
| 원본 | `hams-docs/public/form.io/Basic/TextArea.html` |
| 비교 기준 | `hams-docs/public/form.io/Basic/TextField.html` 및 `TextField-options-spec.md` |
| 컴포넌트 | Form.io Basic / Text Area |
| 탭 | Display, Data, Validation, API, Conditional, Logic, Layout |
| Key 표기 | 컴포넌트 JSON에 저장되는 속성 경로 |

> 원본 HTML에서 확인한 실제 설정 컴포넌트를 기준으로 작성했다. Panel, HTML Element, Container처럼 옵션을 묶거나 설명하는 구조용 컴포넌트는 별도 옵션으로 세지 않고, 그 내부의 저장 가능한 옵션은 모두 표에 포함했다.

## TextField와 다른 옵션

아래 표에는 TextField와 비교해 **TextArea에만 존재하거나, TextArea에서 정의·기본값·노출·동적 선택값이 달라진 항목만** 표시한다. 표에 없는 옵션은 TextField와 동일하다.

| 구분 | 탭 | 옵션 | Key | TextArea | TextField | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| TextArea 전용 | Display | Rows | `rows` | number 입력 | 없음 | textarea의 표시 행 수 |
| 정의 변경 | Display | Widget Type | `widget.type` | 숨김 | `input`, `calendar` 선택 UI 노출 | TextArea HTML에서는 내부 위젯 유형 필드로만 존재 |
| 정의 변경 | Display | Widget Settings | `widget` | JSON 편집기 노출, 기본값 `""` | 조건부 숨김 | TextArea 편집기 설정 객체 입력 |
| TextField 전용 | Display | Input Mask | `inputMask` | 없음 | text 입력 | TextArea에는 저장값용 단일 Input Mask가 없음 |
| TextArea 전용 | Display | Editor | `editor` | `ace`, `ckeditor`, `quill` | 없음 | TextArea 편집기 선택 |
| TextArea 전용 | Display | Auto Expand | `autoExpand` | 기본값 `false` | 없음 | 내용에 맞춰 높이 자동 확장 |
| TextArea 전용 | Display | Enable Uploads | `isUploadEnabled` | 조건부 숨김 | 없음 | 편집기 업로드 활성화 |
| TextArea 전용 | Display | Upload Storage | `uploadStorage` | 조건부 숨김 | 없음 | 업로드 저장소 설정 |
| TextArea 전용 | Display | Upload URL | `uploadUrl` | 조건부 숨김 | 없음 | 업로드 대상 URL |
| TextArea 전용 | Display | Upload Options | `uploadOptions` | 조건부 숨김 | 없음 | 업로드 요청 옵션 |
| TextArea 전용 | Display | Upload Directory | `uploadDir` | 조건부 숨김 | 없음 | 업로드 디렉터리 |
| TextArea 전용 | Display | File Key | `fileKey` | 조건부 숨김 | 없음 | 업로드 파일 FormData Key |
| TextArea 전용 | Display | Upload As | `as` | 조건부 숨김 | 없음 | 업로드 데이터 처리 방식 |
| 정의 변경 | Display | Input Masks | `inputMasks` | 조건부 숨김 | 조건부 숨김 | TextArea에서는 편집기 설정에 의해 노출될 수 있음 |
| TextArea 전용 | Display | WYSIWYG Settings | `wysiwyg` | 조건부 숨김 | 없음 | WYSIWYG 편집기 설정 |
| TextField 전용 | Display | Allow Multiple Masks | `allowMultipleMasks` | 없음 | 기본값 `false` | TextArea에는 없음 |
| TextField 전용 | Display | Hide Input | `mask` | 없음 | 기본값 `false` | TextArea에는 없음 |
| 기본값 변경 | Data | Input Format | `inputFormat` | `html` | `plain` | 선택값 목록은 동일 |
| 동적 목록 변경 | Data | Redraw On | `redrawOn` | `data`, `textField`, `submit` | `data`, `submit` | `textField`는 캡처된 폼의 다른 컴포넌트에서 동적 생성 |
| 동적 목록 변경 | Conditional | When the form component | `conditional.when` | `textField`, `submit` | `submit` | 폼에 존재하는 비교 대상에 따라 동적 생성 |
| 현재 데이터 변경 | Layout | HTML Attributes | `attributes` | 빈 Map | `{ "aaa": "1111", "key": "", "key1": "" }` | 컴포넌트 고정 기본값이 아닌 캡처 당시 편집 데이터 |

> 업로드 관련 옵션은 TextArea HTML에 `formio-hidden` 상태의 설정 컴포넌트로 존재한다. 따라서 누락하지 않고 전체 스펙에 포함했지만, 숨김 상태 HTML에는 선택값과 초기값이 렌더링되지 않아 확인 가능한 범위만 기록했다.

> TextArea HTML에서는 Data의 코드 편집 패널, Validation의 고급 검증 패널, Conditional의 Advanced 패널, Logic 편집 행, PDF Overlay가 접힌 상태라 하위 DOM이 생략되어 있다. 같은 Key의 상위 설정 구조를 TextField HTML과 대조해 공통 하위 옵션을 전체 스펙에 포함했으며, 단순히 펼침 상태가 다른 것은 옵션 정의 차이로 분류하지 않았다.
