# Select 옵션 스펙

## 문서 기준

| 항목 | 내용 |
| --- | --- |
| 원본 | `hams-docs/public/form.io/Basic/Select.html` |
| 비교 기준 | `hams-docs/public/form.io/Basic/TextField.html` 및 `TextField-options-spec.md` |
| 컴포넌트 | Form.io Basic / Select |
| 탭 | Display, Data, Validation, API, Conditional, Logic, Layout |
| Key 표기 | 컴포넌트 JSON에 저장되는 속성 경로 |
| 기본값 판정 | 원본 HTML의 `selected`, `checked`, `value` 기준 |
| 조건부 | 다른 설정을 선택해야 렌더링되는 옵션 |

> 원본 HTML에서 확인한 실제 설정 컴포넌트를 기준으로 작성했다. Panel, HTML Element, Container처럼 옵션을 묶거나 설명하는 구조용 컴포넌트는 별도 옵션으로 세지 않고, 그 내부의 저장 가능한 옵션은 모두 표에 포함했다.

## TextField와 다른 옵션

아래 표에는 TextField와 비교해 **Select에만 존재하거나, Select에서 제외되거나, 형식·노출·선택값이 달라진 항목만** 표시한다. 표에 없는 옵션은 TextField와 동일하다.

| 구분 | 탭 | 옵션 | Key | Select | TextField | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| 정의 변경 | Display | Widget Type | `widget` | `choicesjs`(기본), `html5` | `widget.type`: `input`, `calendar` | Key와 선택값 모두 다름 |
| Select 전용 | Display | Unique Options | `uniqueOptions` | 기본값 `false` | 없음 | 같은 폼의 다른 Select에서 선택된 항목 제외 |
| TextField 전용 | Display | Prefix / Suffix | `prefix`, `suffix` | 없음 | text 입력 | Select에는 없음 |
| TextField 전용 | Display | Mask 계열 | `inputMask`, `displayMask`, `applyMaskOn`, `inputMaskPlaceholderChar`, `allowMultipleMasks`, `inputMasks` | 없음 | 마스크 설정 | 선택값에는 문자열 마스크 미사용 |
| TextField 전용 | Display | Autocomplete | `autocomplete` | 없음 | text 입력 | Select HTML에는 미렌더링 |
| TextField 전용 | Display | Word / Character Counter | `showWordCount`, `showCharCount` | 없음 | 기본값 `false` | 문자열 카운터 |
| TextField 전용 | Display | Hide Input / Spellcheck | `mask`, `spellcheck` | 없음 | boolean 설정 | 문자열 입력 기능 |
| Select 전용 | Data | Data Source Type | `dataSrc` | `values`, `url`, `resource`, `custom`, `json` | 없음 | 선택 항목 공급 방식 |
| 형식 변경 | Data | Default Value | `defaultValue` | select / 선택값 | text / string | 데이터 소스 항목 중 초기값 선택 |
| Select 전용 | Data | Data source configuration | `data.url`, `data.json`, `data.values`, `data.resource`, `data.headers`, `data.custom` | 조건부 설정 | 없음 | 데이터 소스 유형별 설정 |
| Select 전용 | Data | IndexedDB configuration | `indexeddb.database`, `indexeddb.table`, `indexeddb.filter` | 조건부 설정 | 없음 | IndexedDB 데이터 조회 설정 |
| Select 전용 | Data | Value mapping | `valueProperty`, `selectValues`, `selectFields`, `dataType`, `idPath` | 조건부 설정 | 없음 | 응답값 저장 및 표시 경로 설정 |
| Select 전용 | Data | Server search | `searchField`, `searchDebounce`, `minSearch`, `filter`, `sort`, `limit`, `disableLimit` | 조건부 설정 | 없음 | 원격 검색과 조회 제한 |
| Select 전용 | Data | Refresh options | `refreshOn`, `refreshOnBlur`, `clearOnRefresh`, `noRefreshOnScroll` | 새로고침 설정 | 없음 | 다른 값 변경·blur·scroll 연동 |
| Select 전용 | Data | Client search | `searchEnabled`, `selectThreshold`, `useExactSearch` | 검색 설정 | 없음 | 정적 검색 동작 |
| Select 전용 | Data | Resource behavior | `lazyLoad`, `addResource`, `addResourceLabel`, `reference`, `authenticate` | 조건부 설정 | 없음 | Resource 로딩·생성·참조·인증 |
| Select 전용 | Data | Presentation / cache | `template`, `readOnlyValue`, `customOptions`, `ignoreCache` | 표시·Choices.js·캐시 설정 | 없음 | 항목 렌더링과 캐시 동작 |
| TextField 전용 | Data | Input Format | `inputFormat` | 없음 | `plain`, `html`, `raw` | 문자열 정제 형식 미사용 |
| TextField 전용 | Data | Text Case | `case` | 없음 | mixed/uppercase/lowercase | 문자열 변환 미사용 |
| TextField 전용 | Data | Truncate Multiple Spaces | `truncateMultipleSpaces` | 없음 | 기본값 `false` | 문자열 공백 처리 미사용 |
| 노출 변경 | Data | Redraw On | `redrawOn` | 숨김, HTML에 값 미렌더링 | 화면 노출 | Select 원본에서는 조건부 숨김 |
| Select 전용 | Validation | Select validation | `validate.select` | 조건부 숨김 boolean | 없음 | Select 전용 내부 검증 플래그 |
| Select 전용 | Validation | Allow only available values | `validate.onlyAvailableItems` | 기본값 `false` | 없음 | 데이터 소스에 존재하는 값만 허용 |
| TextField 전용 | Validation | Length / Word / Pattern | `validate.minLength`, `validate.maxLength`, `validate.minWords`, `validate.maxWords`, `validate.pattern` | 없음 | 문자열 검증 | Select에는 미제공 |
| 동적 목록 변경 | Conditional | When the form component | `conditional.when` | `textField`, `submit` | `submit` | 폼에 존재하는 비교 대상에 따라 동적 생성 |
| 현재 데이터 변경 | Layout | HTML Attributes | `attributes` | 빈 Map | `{ "aaa": "1111", "key": "", "key1": "" }` | 고정 기본값이 아닌 캡처 당시 편집 데이터 |

> `data.values`의 Label/Value는 저장 구조를 빠짐없이 표현하기 위해 하위 Key로 별도 기재했다. 같은 `valueProperty`는 데이터 소스에 따라 select 또는 text 입력으로 렌더링되므로 두 행으로 구분했다. 접힌 Logic·Conditional·PDF Overlay는 TextField의 동일 구조와 대조해 공통 하위 옵션을 포함했다.
