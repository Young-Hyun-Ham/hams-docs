# Password 옵션 스펙

## 문서 기준

| 항목 | 내용 |
| --- | --- |
| 원본 | `hams-docs/public/form.io/Basic/Password.html` |
| 비교 기준 | `hams-docs/public/form.io/Basic/TextField.html` 및 `TextField-options-spec.md` |
| 컴포넌트 | Form.io Basic / Password |
| 탭 | Display, Data, Validation, API, Conditional, Logic, Layout |
| Key 표기 | 컴포넌트 JSON에 저장되는 속성 경로 |
| 기본값 판정 | 원본 HTML의 `selected`, `checked`, `value` 기준 |
| 조건부 | 다른 설정을 선택해야 렌더링되는 옵션 |

> 원본 HTML에서 확인한 실제 설정 컴포넌트를 기준으로 작성했다. Panel, HTML Element, Container처럼 옵션을 묶거나 설명하는 구조용 컴포넌트는 별도 옵션으로 세지 않고, 그 내부의 저장 가능한 옵션은 모두 표에 포함했다.

## TextField와 다른 옵션

아래 표에는 TextField와 비교해 **Password에서 제외되거나, 정의·기본값·노출·동적 선택값이 달라진 항목만** 표시한다. 표에 없는 옵션은 TextField와 동일하다.

| 구분 | 탭 | 옵션 | Key | Password | TextField | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| 정의 변경 | Display | Widget Type | `widget.type` | 숨김 | `input`, `calendar` 선택 UI 노출 | Password HTML에서는 내부 위젯 유형 필드로만 존재 |
| 정의 변경 | Display | Widget Settings | `widget` | JSON 편집기 노출, 기본값 `""` | 조건부 숨김 | Password 위젯 설정 객체 입력 |
| TextField 전용 | Display | Input Mask | `inputMask` | 없음 | text 입력 | Password에는 없음 |
| TextField 전용 | Display | Allow Multiple Masks | `allowMultipleMasks` | 없음 | 기본값 `false` | Password에는 없음 |
| TextField 전용 | Display | Hide Input | `mask` | 없음 | 기본값 `false` | Password 입력은 자체적으로 가려지므로 별도 옵션 없음 |
| 기본값 변경 | Display | Table View | `tableView` | `false` | `true` | 원본 HTML의 checked 상태 기준 |
| Password 고정 동작 | Data | Password Protection | 저장 Key 없음 | salted bcrypt 단방향 해시로 자동 암호화되고 API에서 반환하지 않음 | 해당 안내 없음 | 설정 옵션이 아닌 Password의 고정 보안 동작 |
| TextField 전용 | Data | Multiple Values | `multiple` | 없음 | 기본값 `false` | Password에는 없음 |
| TextField 전용 | Data | Default Value | `defaultValue` | 없음 | string 입력 | 보안상 Password 기본값을 설정하지 않음 |
| TextField 전용 | Data | Persistent | `persistent` | 없음 | None/Server/Client | Password 저장 방식은 고정 동작 |
| TextField 전용 | Data | Input Format | `inputFormat` | 없음 | `plain`, `html`, `raw` | Password에는 없음 |
| TextField 전용 | Data | Protected | `protected` | 없음 | 기본값 `false` | Password 값은 자동 보호되어 API에서 반환되지 않음 |
| TextField 전용 | Data | Database Index | `dbIndex` | 없음 | 기본값 `false` | Password에는 없음 |
| TextField 전용 | Data | Encrypted | `encrypted` | 없음 | 숨김 옵션 | Password는 bcrypt 해시 동작 사용 |
| 동적 목록 변경 | Data | Redraw On | `redrawOn` | `data`, `textField`, `submit` | `data`, `submit` | `textField`는 캡처된 폼의 다른 컴포넌트에서 동적 생성 |
| TextField 전용 | Data | Custom Default Value | `customDefaultValue` | 없음 | JavaScript/JSONLogic | Password에는 기본값 계산 기능 없음 |
| TextField 전용 | Data | Calculated Value | `calculateValue` | 없음 | JavaScript/JSONLogic | Password에는 계산값 편집 기능 없음 |
| TextField 전용 | Validation | Unique | `unique` | 없음 | 기본값 `false` | Password HTML에는 미렌더링 |
| TextField 전용 | Validation | Minimum Word Length | `validate.minWords` | 없음 | number | Password는 단어 수를 검증하지 않음 |
| TextField 전용 | Validation | Maximum Word Length | `validate.maxWords` | 없음 | number | Password는 단어 수를 검증하지 않음 |
| 동적 목록 변경 | Conditional | When the form component | `conditional.when` | `textField`, `submit` | `submit` | 폼에 존재하는 비교 대상에 따라 동적 생성 |
| 현재 데이터 변경 | Layout | HTML Attributes | `attributes` | `{ "key": "" }` | `{ "aaa": "1111", "key": "", "key1": "" }` | 고정 기본값이 아닌 캡처 당시 편집 데이터 |

> `passwordInfo`는 저장되는 옵션이 아니라 고정 보안 동작을 알리는 HTML 안내 요소이므로 전체 옵션 개수에서는 제외했다. `redrawOn`, `conditional.when`, HTML Attributes의 차이는 캡처된 폼 문맥·편집 데이터에 따른 값이다.
