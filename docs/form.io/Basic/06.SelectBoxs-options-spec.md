# Select Boxes 옵션 스펙

## 문서 기준

| 항목 | 내용 |
| --- | --- |
| 원본 | `hams-docs/public/form.io/Basic/SelectBoxs.html` |
| 비교 기준 | `hams-docs/public/form.io/Basic/TextField.html` 및 `TextField-options-spec.md` |
| 컴포넌트 | Form.io Basic / Select Boxes |
| 탭 | Display, Data, Validation, API, Conditional, Logic, Layout |
| Key 표기 | 컴포넌트 JSON에 저장되는 속성 경로 |

> 원본 HTML에서 확인한 실제 설정 컴포넌트를 기준으로 작성했다. Panel, HTML Element, Container처럼 옵션을 묶거나 설명하는 구조용 컴포넌트는 별도 옵션으로 세지 않고, 그 내부의 저장 가능한 옵션은 모두 표에 포함했다.

## TextField와 다른 옵션

아래 표에는 TextField와 비교해 **Select Boxes에만 존재하거나, Select Boxes에서 제외되거나, 형식·기본값·노출이 달라진 항목만** 표시한다. 표에 없는 옵션은 TextField와 동일하다.

| 구분 | 탭 | 옵션 | Key | Select Boxes | TextField | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| Select Boxes 전용 | Display | Options Label Position | `optionsLabelPosition` | `right` 기본, `top/left/right/bottom` | 없음 | 각 선택 항목 라벨 위치 |
| Select Boxes 전용 | Display | Inline Layout | `inline` | 기본값 `false` | 없음 | 항목을 한 줄에 배치 |
| TextField 전용 | Display | Placeholder | `placeholder` | 없음 | text 입력 | 선택 상자에는 미제공 |
| TextField 전용 | Display | Prefix / Suffix | `prefix`, `suffix` | 없음 | text 입력 | Select Boxes에는 없음 |
| TextField 전용 | Display | Widget 계열 | `widget.type`, `widget` | 없음 | 위젯 선택 및 설정 | Select Boxes에는 없음 |
| TextField 전용 | Display | Mask 계열 | `inputMask`, `displayMask`, `applyMaskOn`, `inputMaskPlaceholderChar`, `allowMultipleMasks`, `inputMasks` | 없음 | 마스크 설정 | 선택값에는 문자열 마스크 미사용 |
| TextField 전용 | Display | Autocomplete | `autocomplete` | 없음 | text 입력 | Select Boxes HTML에는 미렌더링 |
| TextField 전용 | Display | Word / Character Counter | `showWordCount`, `showCharCount` | 없음 | 기본값 `false` | 문자열 카운터 |
| TextField 전용 | Display | Hide Input | `mask` | 없음 | 기본값 `false` | Select Boxes에는 없음 |
| TextField 전용 | Display | Allow Spellcheck | `spellcheck` | 없음 | 기본값 `true` | 문자열 입력 기능 |
| 기본값 변경 | Display | Table View | `tableView` | `false` | `true` | 원본 HTML의 checked 상태 기준 |
| Select Boxes 전용 | Data | Data Source Type | `dataSrc` | `values`(기본), `url` | 없음 | 정적 Values 또는 원격 URL 사용 |
| 형식 변경 | Data | Default Value | `defaultValue` | selectboxes / object, 기본 선택 없음 | text / string | 선택 항목 Key별 boolean Map |
| Select Boxes 전용 | Data | Data URL | `data.url` | 조건부 text | 없음 | URL 데이터 소스 주소 |
| Select Boxes 전용 | Data | Values | `values` | Label/Value/Shortcut 행 배열 | 없음 | 정적 선택 항목 목록 |
| Select Boxes 전용 | Data | Request Headers | `data.headers` | 조건부 배열 | 없음 | URL 요청 헤더 |
| Select Boxes 전용 | Data | Value Property | `valueProperty` | 조건부 string | 없음 | 응답에서 값으로 사용할 경로 |
| Select Boxes 전용 | Data | Item Template | `template` | 조건부 template | 없음 | 원격 항목 표시 템플릿 |
| Select Boxes 전용 | Data | Authenticate | `authenticate` | 조건부 boolean | 없음 | 인증 정보를 URL 요청에 포함 |
| Select Boxes 전용 | Data | Ignore Cache | `ignoreCache` | 조건부 boolean | 없음 | URL 응답 캐시 무시 |
| TextField 전용 | Data | Multiple Values | `multiple` | 없음 | 기본값 `false` | Select Boxes 자체가 복수 boolean Map |
| TextField 전용 | Data | Input Format | `inputFormat` | 없음 | `plain`, `html`, `raw` | 문자열 정제 형식 미사용 |
| TextField 전용 | Data | Text Case | `case` | 없음 | mixed/uppercase/lowercase | 문자열 변환 미사용 |
| TextField 전용 | Data | Truncate Multiple Spaces | `truncateMultipleSpaces` | 없음 | 기본값 `false` | 문자열 공백 처리 미사용 |
| 노출 변경 | Data | Redraw On | `redrawOn` | 숨김, HTML에 값 미렌더링 | 화면 노출 | Select Boxes 원본에서는 조건부 숨김 |
| Select Boxes 전용 | Validation | Allow only available values | `validate.onlyAvailableItems` | 기본값 `false` | 없음 | 정의된 항목만 허용 |
| Select Boxes 전용 | Validation | Minimum / Maximum checked number | `validate.minSelectedCount`, `validate.maxSelectedCount` | number | 없음 | 최소·최대 선택 개수 |
| Select Boxes 전용 | Validation | Selection count messages | `minSelectedCountMessage`, `maxSelectedCountMessage` | string | 없음 | 최소·최대 선택 개수 오류 메시지 |
| TextField 전용 | Validation | Validate On | `validateOn` | 없음 | `change`, `blur` | Select Boxes HTML에는 미렌더링 |
| TextField 전용 | Validation | Unique | `unique` | 없음 | 기본값 `false` | Select Boxes HTML에는 미렌더링 |
| TextField 전용 | Validation | Length / Word 검증 | `validate.minLength`, `validate.maxLength`, `validate.minWords`, `validate.maxWords` | 없음 | number 입력 | 문자열 전용 검증 |
| TextField 전용 | Validation | Regular Expression Pattern | `validate.pattern` | 없음 | regex string | 문자열 전용 검증 |
| 동적 목록 변경 | Conditional | When the form component | `conditional.when` | `textField`, `submit` | `submit` | 폼에 존재하는 비교 대상에 따라 동적 생성 |
| 현재 데이터 변경 | Layout | HTML Attributes | `attributes` | 빈 Map | `{ "aaa": "1111", "key": "", "key1": "" }` | 고정 기본값이 아닌 캡처 당시 편집 데이터 |

> Values 내부의 Label, Value, Shortcut은 독립 컴포넌트 최상위 옵션은 아니지만 저장 스키마를 빠짐없이 나타내기 위해 전체 스펙에 하위 Key로 포함했다. 접힌 Logic·Conditional·PDF Overlay는 TextField의 동일 구조와 대조해 공통 하위 옵션을 포함했다.
