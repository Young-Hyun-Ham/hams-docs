# Button 옵션 스펙

## 문서 기준

| 항목 | 내용 |
| --- | --- |
| 원본 | `hams-docs/public/form.io/Basic/Button.html` |
| 비교 기준 | `hams-docs/public/form.io/Basic/TextField.html` 및 `TextField-options-spec.md` |
| 컴포넌트 | Form.io Basic / Button |
| 탭 | Display, API, Conditional, Logic, Layout |
| Key 표기 | 컴포넌트 JSON에 저장되는 속성 경로 |
| 기본값 판정 | 원본 HTML의 `selected`, `checked`, `value` 기준 |
| 조건부 | 다른 설정을 선택해야 렌더링되는 옵션 |

> 원본 HTML에서 확인한 실제 설정 컴포넌트를 기준으로 작성했다. Panel, HTML Element, Container처럼 옵션을 묶거나 설명하는 구조용 컴포넌트는 별도 옵션으로 세지 않고, 그 내부의 저장 가능한 옵션은 모두 표에 포함했다.

## TextField와 다른 옵션

아래 표에는 TextField와 비교해 **Button에만 존재하거나, Button에서 제외되거나, 기본값·노출·탭 구조가 달라진 항목만** 표시한다. 표에 없는 옵션은 TextField와 동일하다.

| 구분 | 탭 | 옵션 | Key | Button | TextField | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| 탭 제외 | 전체 | Data 탭 | - | 없음 | 18개 논리 옵션 | Button은 사용자 입력 데이터를 저장하는 필드가 아님 |
| 탭 제외 | 전체 | Validation 탭 | - | 없음 | 15개 논리 옵션 | Button에는 필드 값 검증 탭이 없음 |
| Button 전용 | Display | Action | `action` | `submit`, `saveState`, `event`, `custom`, `reset`, `oauth`, `url` | 없음 | 버튼 실행 동작 |
| Button 전용 | Display | OAuth Provider | `oauthProvider` | Action=`oauth`, 숨김 | 없음 | OAuth 공급자 |
| Button 전용 | Display | State | `state` | Action=`saveState`, 숨김 | 없음 | 저장할 상태명 |
| Button 전용 | Display | Save On Enter | `saveOnEnter` | 기본값 `false` | 없음 | Enter 키로 저장/제출 |
| Button 전용 | Display | Show Validations | `showValidations` | 조건부 숨김 | 없음 | 제출 시 검증 표시 여부 |
| Button 전용 | Display | Event | `event` | Action=`event`, 숨김 | 없음 | 발생시킬 이벤트명 |
| Button 전용 | Display | URL | `url` | Action=`url`, 숨김 | 없음 | POST 대상 URL |
| Button 전용 | Display | Custom Action | `custom` | Action=`custom`, 숨김 | 없음 | 사용자 정의 JavaScript |
| Button 전용 | Display | Headers | `headers` | Action=`url`, 숨김 | 없음 | POST 요청 헤더 목록 |
| Button 전용 | Display | Theme | `theme` | `primary` 기본 | 없음 | Bootstrap 버튼 테마 |
| Button 전용 | Display | Size | `size` | `md` 기본 | 없음 | `sm`, `md`, `lg` |
| Button 전용 | Display | Block Button | `block` | 기본값 `false` | 없음 | 전체 너비 버튼 |
| Button 전용 | Display | Left / Right Icon | `leftIcon`, `rightIcon` | icon class string | 없음 | 버튼 양쪽 아이콘 |
| Button 전용 | Display | Shortcut | `shortcut` | 빈 값 또는 `A`~`Z` | 없음 | 키보드 단축키 |
| Button 전용 | Display | Disable on Form Invalid | `disableOnInvalid` | 기본값 `false` | 없음 | 폼이 유효하지 않으면 버튼 비활성화 |
| TextField 전용 | Display | Label Position | `labelPosition` | 없음 | 위치 선택 | Button에는 별도 라벨 위치가 없음 |
| TextField 전용 | Display | Placeholder / Prefix / Suffix | `placeholder`, `prefix`, `suffix` | 없음 | text 입력 | Button에는 없음 |
| TextField 전용 | Display | Widget / Mask 계열 | `widget.type`, `widget`, `inputMask`, `displayMask`, `applyMaskOn`, `inputMaskPlaceholderChar`, `allowMultipleMasks`, `inputMasks` | 없음 | 입력 위젯·마스크 | Button에는 없음 |
| TextField 전용 | Display | Autocomplete / Counters / Mask / Spellcheck | `autocomplete`, `showWordCount`, `showCharCount`, `mask`, `spellcheck` | 없음 | 문자열 입력 설정 | Button에는 없음 |
| TextField 전용 | Display | Data Grid Label | `dataGridLabel` | 없음 | 조건부 숨김 | Button에는 없음 |
| 노출 변경 | Display | Hide Label | `hideLabel` | 숨김 | 화면 노출 | Button 원본에서는 설정 컴포넌트만 숨김 상태로 존재 |
| 기본값 변경 | Display | Table View | `tableView` | `false` | `true` | 원본 HTML의 checked 상태 기준 |
| 동적 목록 변경 | Conditional | When the form component | `conditional.when` | `textField`, `submit` | `submit` | 폼에 존재하는 비교 대상에 따라 동적 생성 |
| 현재 데이터 변경 | Layout | HTML Attributes | `attributes` | 빈 Map | `{ "aaa": "1111", "key": "", "key1": "" }` | 고정 기본값이 아닌 캡처 당시 편집 데이터 |

> Button HTML의 Logic과 PDF Overlay는 접힌 상태이므로 TextField의 동일 공통 구조와 대조해 하위 옵션을 포함했다. Action별 숨김 옵션은 현재 HTML에 값·선택지가 렌더링되지 않은 경우 확인 가능한 형식만 기록했다.
