# Checkbox 옵션 스펙

## 문서 기준

| 항목 | 내용 |
| --- | --- |
| 원본 | `hams-docs/public/form.io/Basic/Checkbox.html` |
| 비교 기준 | `hams-docs/public/form.io/Basic/TextField.html` 및 `TextField-options-spec.md` |
| 컴포넌트 | Form.io Basic / Checkbox |
| 탭 | Display, Data, Validation, API, Conditional, Logic, Layout |
| Key 표기 | 컴포넌트 JSON에 저장되는 속성 경로 |
| 기본값 판정 | 원본 HTML의 `selected`, `checked`, `value` 기준 |
| 조건부 | 다른 설정을 선택해야 렌더링되는 옵션 |

> 원본 HTML에서 확인한 실제 설정 컴포넌트를 기준으로 작성했다. Panel, HTML Element, Container처럼 옵션을 묶거나 설명하는 구조용 컴포넌트는 별도 옵션으로 세지 않고, 그 내부의 저장 가능한 옵션은 모두 표에 포함했다.

## TextField와 다른 옵션

아래 표에는 TextField와 비교해 **Checkbox에만 존재하거나, Checkbox에서 제외되거나, 형식·기본값·동적 선택값이 달라진 항목만** 표시한다. 표에 없는 옵션은 TextField와 동일하다.

| 구분 | 탭 | 옵션 | Key | Checkbox | TextField | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| Checkbox 전용 | Display | Shortcut | `shortcut` | `A`~`Z` 또는 빈 값 | 없음 | 키보드 단축키 |
| Checkbox 전용 | Display | Input Type | `inputType` | `checkbox`(기본), `radio` | 없음 | 렌더링할 선택 입력 유형 |
| Checkbox 전용 | Display | Name | `name` | 조건부 숨김 text | 없음 | Radio 입력의 HTML name |
| Checkbox 전용 | Display | Value | `value` | 조건부 숨김 text | 없음 | Radio 입력의 HTML value |
| TextField 전용 | Display | Label Position 계열 | `labelPosition`, `labelWidth`, `labelMargin` | 없음 | 위치·너비·여백 설정 | Checkbox 라벨 배치 구조에는 미제공 |
| TextField 전용 | Display | Placeholder | `placeholder` | 없음 | text 입력 | Checkbox에는 입력 Placeholder가 없음 |
| TextField 전용 | Display | Prefix / Suffix | `prefix`, `suffix` | 없음 | text 입력 | Checkbox에는 없음 |
| TextField 전용 | Display | Widget 계열 | `widget.type`, `widget` | 없음 | 위젯 선택 및 설정 | Checkbox에는 없음 |
| TextField 전용 | Display | Mask 계열 | `inputMask`, `displayMask`, `applyMaskOn`, `inputMaskPlaceholderChar`, `allowMultipleMasks`, `inputMasks` | 없음 | 마스크 설정 | Checkbox boolean 입력에는 없음 |
| TextField 전용 | Display | Autocomplete | `autocomplete` | 없음 | text 입력 | Checkbox HTML에는 미렌더링 |
| TextField 전용 | Display | Word / Character Counter | `showWordCount`, `showCharCount` | 없음 | 기본값 `false` | 문자열 카운터 |
| TextField 전용 | Display | Hide Input | `mask` | 없음 | 기본값 `false` | Checkbox에는 없음 |
| TextField 전용 | Display | Allow Spellcheck | `spellcheck` | 없음 | 기본값 `true` | 문자열 입력 기능 |
| 기본값 변경 | Display | Table View | `tableView` | `false` | `true` | 원본 HTML의 checked 상태 기준 |
| 형식 변경 | Data | Default Value | `defaultValue` | checkbox / boolean, 기본값 `false` | text / string, 빈 문자열 | Checkbox의 초기 체크 상태 |
| TextField 전용 | Data | Multiple Values | `multiple` | 없음 | 기본값 `false` | Checkbox HTML에는 없음 |
| TextField 전용 | Data | Input Format | `inputFormat` | 없음 | `plain`, `html`, `raw` | boolean 값에는 문자열 정제 형식 미사용 |
| TextField 전용 | Data | Text Case | `case` | 없음 | mixed/uppercase/lowercase | boolean 값에는 미사용 |
| TextField 전용 | Data | Truncate Multiple Spaces | `truncateMultipleSpaces` | 없음 | 기본값 `false` | boolean 값에는 미사용 |
| 동적 목록 변경 | Data | Redraw On | `redrawOn` | `data`, `textField`, `submit` | `data`, `submit` | `textField`는 캡처된 폼 문맥에서 동적 생성 |
| TextField 전용 | Validation | Validate On | `validateOn` | 없음 | `change`, `blur` | Checkbox HTML에는 미렌더링 |
| TextField 전용 | Validation | Unique | `unique` | 없음 | 기본값 `false` | Checkbox HTML에는 미렌더링 |
| TextField 전용 | Validation | Length / Word 검증 | `validate.minLength`, `validate.maxLength`, `validate.minWords`, `validate.maxWords` | 없음 | number 입력 | 문자열 전용 검증 |
| TextField 전용 | Validation | Regular Expression Pattern | `validate.pattern` | 없음 | regex string | 문자열 전용 검증 |
| 동적 목록 변경 | Conditional | When the form component | `conditional.when` | `textField`, `submit` | `submit` | 폼에 존재하는 비교 대상에 따라 동적 생성 |
| 현재 데이터 변경 | Layout | HTML Attributes | `attributes` | `{ "key": "" }` | `{ "aaa": "1111", "key": "", "key1": "" }` | 고정 기본값이 아닌 캡처 당시 편집 데이터 |

> `redrawOn`, `conditional.when`, HTML Attributes의 차이는 컴포넌트 고정 스펙이 아니라 캡처된 폼 문맥·편집 데이터에 따른 값이다.

| ---: | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | HTML Attributes | 입력 엘리먼트에 HTML 속성 추가. Form.io 생성 속성이 우선 |  |  | 항상 | 원본 예시 `{ "key": "" }` | Attribute Name/Value Map | `attributes` | datamap | object |
| 2 | PDF Overlay Style | PDF 폼 오버레이 스타일 |  |  | PDF Overlay | 빈 문자열 | CSS 스타일 문자열 | `overlay.style` | text | string |
| 3 | PDF Overlay Page | 오버레이를 표시할 PDF 페이지 |  |  | PDF Overlay | 빈 문자열 | 페이지 번호 | `overlay.page` | text | number-like string |
| 4 | PDF Overlay Left | 오버레이의 수평 위치 |  |  | PDF Overlay | 빈 문자열 | 좌측 좌표 | `overlay.left` | text | number-like string |
| 5 | PDF Overlay Top | 오버레이의 수직 위치 |  |  | PDF Overlay | 빈 문자열 | 상단 좌표 | `overlay.top` | text | number-like string |

> Layout HTML의 `data[type]` hidden 필드와 `data[checkbox]` 입력은 우측 미리보기 Form에 속한 렌더링 데이터다. Checkbox 설정 옵션이 아니므로 표에서 제외했다. `attributes` 내부의 `__key`와 동적 Value 입력도 DataMap 행 편집 필드이며 각각을 독립 옵션으로 세지 않았다.
