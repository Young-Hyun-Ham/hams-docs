| ---: | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Label | 이 필드의 레이블입니다. |  |  | 항상 | Empty string | String | `label` | text | string |

| 4 | Column Properties | 각 열의 크기와 너비를 설정합니다. 한 행의 전체 너비는 12입니다. 예를 들어 두 열이 페이지 전체를 채우려면 각각 6과 6으로 설정합니다. |  |  | 항상 | Empty | - | `columns` | datagrid | array |
| 5 | Size | 크기 설정 |  |  | 항상 | `md` | `xs`, `sm`, `md`, `lg`, `xl` | `columns[].size` | select | enum |

| 7 | Auto adjust columns | 중첩된 컴포넌트의 숨김 여부에 따라 열을 자동으로 조정합니다. |  |  | 항상 | `false` | `true`, `false` | `autoAdjust` | checkbox | boolean |
| 8 | Custom CSS Class | 이 컴포넌트에 추가할 사용자 지정 CSS 클래스입니다. |  |  | 항상 | Empty string | String | `customClass` | text | string |
| 9 | Hidden | 숨김 필드는 폼에 포함되지만 화면에는 표시되지 않습니다. |  |  | 항상 | `false` | `true`, `false` | `hidden` | checkbox | boolean |
| 10 | Data Grid Label | 데이터 그리드 레이블 설정 |  |  | 조건부 / 숨김 | Empty | `true`, `false` | `dataGridLabel` | checkbox | boolean |
| 11 | Modal Edit | 이 컴포넌트의 값을 편집할 수 있는 모달을 엽니다. |  |  | 항상 | `false` | `true`, `false` | `modalEdit` | checkbox | boolean |
