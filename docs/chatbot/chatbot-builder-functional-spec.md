# Chatbot Builder 기능명세

## 1. 문서 개요

- 대상: `src/app/builder/react-flow`의 Chatbot Builder
- 기준: 2026-07-28 소스 코드의 현재 구현
- 목적: 기획, 개발, QA가 화면별 기능과 상태 전이를 동일하게 이해하도록 한다.
- 화면 구성: 시나리오 목록, 시나리오 플로우 편집, 시나리오 버전 조회

> 본 문서는 코드 기반 As-Is 명세다. 번역 키가 그대로 노출되거나 구현상 동작이 불완전한 부분도 의도된 요구사항으로 보정하지 않고 별도 유의사항으로 기록했다.

## 3. 공통 데이터

### 3.1 시나리오

| 필드 | 의미 | 화면 사용처 |
|---|---|---|
| `id` | 시나리오 식별자 | 조회, 수정, 삭제, 이동 |
| `name` | 시나리오명 | 카드, 검색, 편집 탭 |
| `description` | 설명 | 생성/수정 팝업 |
| `nodes` / `edges` | 플로우 노드/연결선 | 편집, 조회, 실행, 저장 |
| `start_node_id` | 시작 노드 | 실행 시작점, 저장 |
| `ltst_ver_id` | 최신 버전 | 버전 조회 기본값 |
| `depn_ver_id` | 배포 버전 | 배포 여부/카드 강조/필터 |
| `groupId`, `versions` | 버전 그룹과 표시 버전 | 버전 트리 구성 |
| `created_at`, `updated_at` | 생성/수정 일시 | 상세 팝업, 정렬, 기간 필터 |

### 3.2 공통 상태 원칙

- 시나리오, 노드, 엣지, 선택 노드, 시작 노드는 Zustand Builder Store에서 화면 간 공유한다.
- 비동기 목록/상세 작업 중 로딩 오버레이를 표시한다.
- 편집 화면의 노드 속성은 우측 Controller에서 로컬 편집 후 `Save Changes`를 눌러야 캔버스 상태에 반영된다.
- 캔버스 상태 저장과 배포는 별도 작업이다. `Save/Commit`, `Push`, `Deploy`를 동일한 기능으로 취급하지 않는다.

## 5. 공통 권한·오류·접근성

- 코드상 별도 화면 접근 권한 검사는 확인되지 않는다. 단, 노드 수정 권한이 없을 때 경고를 표시하는 분기가 있다.
- API 오류는 기능별로 로딩 해제, 브라우저 alert, Snackbar 또는 콘솔 오류 처리 방식이 혼재한다.
- 버튼 일부는 `Enter` 키를 지원하고 React Flow는 키보드 단축키를 제공하지만, 컨텍스트 메뉴와 커스텀 div 버튼의 접근성은 일관되지 않다.
- 모든 사용자 노출 문구는 `t()` 번역을 전제로 하나 일부 한글/영문 문자열이 직접 선언되어 있다.
